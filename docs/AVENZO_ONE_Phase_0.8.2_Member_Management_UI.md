# AVENZO ONE — Phase 0.8.2 Member Management UI

สถานะ: Implemented, deployed and verified on Supabase project `eigrllibviqjddenjuch`

## สิ่งที่เพิ่ม

- ตารางสมาชิกแสดงชื่อเล่น อีเมล ตำแหน่งงาน Role, Branch Scope และสถานะ
- ฟอร์มแก้ชื่อแสดงและตำแหน่งงาน
- เปลี่ยน Role และ Branch Scope แบบ transaction เดียว
- พักสิทธิ์ชั่วคราว เปิดสิทธิ์คืน และยกเลิกสมาชิกพร้อมเหตุผล
- สมาชิกที่ยกเลิกใช้ Soft Remove และต้องเชิญใหม่หากต้องการเพิ่มกลับ
- บันทึก Audit Event สำหรับโปรไฟล์ สิทธิ์ และสถานะ

## กฎความปลอดภัย

- การเขียนทั้งหมดผ่าน RPC ฝั่งฐานข้อมูล ไม่มีสิทธิ์เขียนตารางโดยตรงจาก Browser
- ต้องมี `member.update` สำหรับแก้ข้อมูลหรือสถานะ
- ต้องมีทั้ง `member.update` และ `role.manage` สำหรับเปลี่ยน Role/Scope
- Admin ไม่สามารถจัดการ Owner ได้ เฉพาะ Owner เท่านั้น
- ห้ามลด Role, พักสิทธิ์ หรือยกเลิก Owner คนสุดท้าย
- Owner ใช้ได้เฉพาะ Scope ทั้ง Organization
- Admin จะไม่เห็นเครื่องมือจัดการ Owner และไม่สามารถเชิญหรือแต่งตั้ง Owner ได้
- การยกเลิกสมาชิกไม่ลบบัญชี Supabase Auth และไม่กระทบ Organization อื่น

## การตรวจสอบ

- TypeScript (`tsc --noEmit`) ผ่าน
- ทดสอบแก้ชื่อ/ตำแหน่ง, พักสิทธิ์ และเปิดสิทธิ์คืนใน transaction ผ่าน
- ยืนยันว่าทุกการเปลี่ยนแปลงสร้าง Audit Event
- ยืนยันว่าระบบป้องกัน Owner คนสุดท้าย
- ยืนยันว่าผู้ไม่มีสิทธิ์และ Admin ที่พยายามจัดการ Owner ถูกปฏิเสธ
- ยืนยันว่า Owner เชิญ Owner ได้ แต่ Admin เชิญ Owner ไม่ได้
- การทดสอบฐานข้อมูลใช้ transaction และ rollback จึงไม่เปลี่ยนข้อมูลสมาชิกจริง

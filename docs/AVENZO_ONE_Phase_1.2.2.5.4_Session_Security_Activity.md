# Phase 1.2.2.5.4 — ประวัติกิจกรรมความปลอดภัยของ Session

## ผลลัพธ์

- เจ้าของบัญชีเห็นกิจกรรม Session ล่าสุดได้สูงสุด 20 รายการ
- แสดงเหตุการณ์เริ่ม Session, เปลี่ยนนโยบาย, ออกจากระบบอุปกรณ์เดียว และออกจากระบบอุปกรณ์อื่นทั้งหมดเป็นภาษาไทย
- แสดงเฉพาะชื่ออุปกรณ์ เบราว์เซอร์ ระบบปฏิบัติการ เวลา และ Policy ที่จำเป็น
- RPC ผูกผู้ใช้ด้วย `auth.uid()` และ Session ปัจจุบันจาก JWT เท่านั้น

## ขอบเขตความปลอดภัย

- ตาราง Audit อยู่ใน Schema `private` และ Account ทั่วไปอ่านตรงไม่ได้
- RPC ไม่คืน Raw Session ID, User ID, Event Metadata, Token หรือ IP Address
- จำนวนข้อมูลถูกจำกัด 1–50 รายการ โดย UI ขอเพียง 20 รายการล่าสุด
- เหตุการณ์ที่ไม่รู้จักในอนาคตจะแสดงชื่อกลาง ไม่แสดง Payload ดิบ

## วิธีทดสอบ Local

1. Login แล้วเปิด `/account/security/sessions`
2. ตรวจว่ามีหัวข้อ **ประวัติกิจกรรมความปลอดภัย** ใต้รายการอุปกรณ์
3. หากมีอุปกรณ์อื่น ให้สั่งออกจากระบบหนึ่งเครื่อง แล้ว Refresh
4. ต้องเห็นเหตุการณ์ **ออกจากระบบอุปกรณ์** พร้อมชื่ออุปกรณ์และเวลา
5. ต้องไม่พบ Token, Session ID ดิบ, User ID, Metadata หรือ IP Address บนหน้า

## แผนถัดไป

Phase 1.2.2.5.5 — แจ้งเตือนความปลอดภัยเมื่อมี Session ใหม่หรือมีคำสั่งออกจากระบบหลายอุปกรณ์ โดยยังไม่ส่งข้อมูลลับในอีเมล

# AVENZO ONE — Rapid-UI-08 Validation and Submit Preview Report

**Status:** Owner Approved — Checkpoint Closed
**Approved date:** 21 August 2026
**Scope:** Live Sale Rapid Entry UI only  
**Data safety:** ไม่มีการสร้าง Product/SKU, อัปโหลดภาพ, เพิ่ม Stock หรือเรียก Backend

## สิ่งที่ทำ

- เพิ่มสรุปความพร้อมของ 50 แถว: พร้อมสร้าง, ต้องแก้ไข, ยังไม่กรอก และเลือกพร้อมสร้าง
- แถวที่ผู้ใช้ยังไม่แตะจะถูกถือเป็นแถวว่างและไม่นำไปรวมในพรีวิว
- เมื่อเริ่มกรอกแถวแล้ว ระบบบังคับราคาและสต็อก พร้อมตรวจชื่อ หมวดหมู่ หน่วย สาขา และภาพ
- ปุ่ม “เลือกเฉพาะรายการพร้อมสร้าง” เลือกเฉพาะแถวที่ผ่านทุกเงื่อนไข
- ปุ่ม “ตรวจรายการที่เลือก” เปิดพรีวิวเฉพาะรายการที่เลือกและพร้อมสร้าง
- หากข้อมูลผิด ระบบเลื่อนไปยังช่องแรกที่ต้องแก้และโฟกัสช่องนั้น
- เพิ่มสถานะแถว: ยังไม่กรอก, ต้องแก้ไข, กำลังแก้ไข, พร้อมสร้าง และเลือกพร้อมสร้าง
- ไม่มีข้อความหรือพฤติกรรมแบบสำเร็จบางส่วน

## วิธีทดสอบบน localhost

1. เปิดหน้า `Products → สร้างสินค้าขายด่วน / Live Sale`
2. จองช่วงรหัส แล้วเข้า “กรอกสินค้าแบบตาราง”
3. เว้นบางแถวว่าง กรอกบางแถวให้ครบ และกรอกอีกแถวโดยเว้นราคา/สต็อก
4. ตรวจตัวเลขสรุปว่าแยกสถานะถูกต้อง
5. กด “เลือกเฉพาะรายการพร้อมสร้าง” แล้วตรวจว่าไม่เลือกแถวว่างหรือแถวผิด
6. เลือกแถวที่ผิดแล้วกด “ตรวจรายการที่เลือก” ระบบต้องพาไปยังช่องแรกที่ต้องแก้
7. แก้ข้อมูลให้ครบแล้วกดตรวจอีกครั้ง ต้องเห็นพรีวิวเฉพาะรายการพร้อมสร้าง
8. กด “ยืนยันรายการที่เลือก” ต้องแสดงผล UI Preview เท่านั้นและไม่มีข้อมูลจริงถูกบันทึก

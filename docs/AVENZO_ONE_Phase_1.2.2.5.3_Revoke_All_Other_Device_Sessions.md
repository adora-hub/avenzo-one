# Phase 1.2.2.5.3 — ออกจากระบบอุปกรณ์อื่นทั้งหมด

## ผลลัพธ์

- ผู้ใช้สั่งออกจากระบบทุกอุปกรณ์อื่นของบัญชีตนเองได้ในครั้งเดียว
- Session ของอุปกรณ์ปัจจุบันถูกยกเว้นทั้งใน UI และ RPC ฝั่งฐานข้อมูล
- มีหน้าตรวจสอบและปุ่มยืนยันชัดเจนก่อนดำเนินการ
- RPC ใช้ `auth.uid()` และ `session_id` จาก JWT ฝั่ง Server โดยไม่รับ User ID หรือเหตุผลจาก Browser
- บันทึก `session_other_devices_revoked` ใน Private Audit Log แยกหนึ่ง Event ต่ออุปกรณ์
- ไม่แสดง Token, Session ID ดิบ หรือ IP Address

## ขอบเขตความปลอดภัย

คำสั่งนี้ยกเลิก App Session ของ AVENZO ONE อุปกรณ์อื่นทั้งหมดที่ยัง Active เมื่ออุปกรณ์เหล่านั้นเปิดหน้าที่มีการป้องกันครั้งถัดไป Middleware จะพากลับหน้า Login ส่วน Supabase JWT เดิมจะหมดอายุตามอายุ Token ของ Supabase

## วิธีทดสอบ Local

1. Login บัญชีเดียวกันอย่างน้อย 3 บริบท เช่น Chrome ปกติ, Chrome Incognito และ Edge
2. เปิดหน้าที่ต้อง Login ในทั้ง 3 บริบท เพื่อให้ Session ถูกลงทะเบียน
3. ที่บริบทหลัก เปิด `/account/security/sessions`
4. การ์ดด้านบนต้องแสดงจำนวนอุปกรณ์อื่นที่ Active เป็น 2 อุปกรณ์
5. กด `ออกจากระบบอุปกรณ์อื่นทั้งหมด` และตรวจข้อความยืนยันว่าอุปกรณ์ปัจจุบันจะไม่หลุด
6. กด `ยืนยันออกจากระบบทั้งหมด`
7. บริบทหลักต้องยังใช้งานต่อได้
8. กลับไป Incognito และ Edge แล้ว Refresh หน้าที่มีการป้องกัน ทั้งสองต้องถูกพากลับหน้า Login
9. Refresh หน้ารายการอุปกรณ์ในบริบทหลัก การ์ดทั้งสองต้องเป็น `ออกจากระบบแล้ว`

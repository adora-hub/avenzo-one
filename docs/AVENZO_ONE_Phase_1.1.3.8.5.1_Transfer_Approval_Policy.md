# Phase 1.1.3.8.5.1 — Transfer Approval Policy

สถานะ: พัฒนา Local รอผู้ใช้ทดสอบ

## เป้าหมาย

ให้ Super Admin กำหนดวงเงินที่ Platform Admin คนเดียวอนุมัติรายการโอนได้ พร้อมกติกาว่ารายการเสี่ยงต้องใช้ผู้ดูแลสองคนเสมอ

## ขอบเขตเฟสนี้

- ค่าเริ่มต้น: อนุมัติคนเดียวได้ไม่เกิน 5,000 บาท
- ยอดเกินวงเงิน: ต้องใช้ Platform Admin สองบัญชี
- รายการมีสัญญาณเสี่ยง: ต้องใช้สองบัญชีเสมอ
- แก้ไขได้เฉพาะ Super Admin ที่ผ่าน MFA (AAL2)
- ทุกการเปลี่ยนแปลงมี Command ID, Version check และ Audit Event แบบแก้ย้อนหลังไม่ได้
- หน้าจอมีขั้นตรวจสอบครั้งสุดท้ายก่อนบันทึก

## ขอบเขตความปลอดภัย

Phase นี้บันทึกและแสดงนโยบายเท่านั้น ยังไม่ลดกฎ Two-person Approval เดิม การนำกฎไปตัดสินการรับชำระจริงเป็น Phase 1.1.3.8.5.2

## วิธีทดสอบ Local

1. Login ด้วย Super Admin และผ่าน MFA
2. เปิด `/platform-admin/billing/transfer-proofs`
3. ตั้งวงเงิน เช่น `5000` และกรอกเหตุผลอย่างน้อย 10 ตัวอักษร
4. กด `ตรวจสอบก่อนบันทึก`
5. ตรวจข้อความสรุป แล้วกด `ยืนยันบันทึกนโยบาย`
6. ต้องเห็นข้อความบันทึกสำเร็จและ Version เพิ่มขึ้น
7. Login ด้วย Platform Admin ปกติ ต้องดูนโยบายได้แต่แก้ไขไม่ได้

## แผนถัดไป

Phase 1.1.3.8.5.2 — นำนโยบายไปบังคับใช้ใน RPC รับชำระจริง พร้อมกฎ Risk override และ Regression tests

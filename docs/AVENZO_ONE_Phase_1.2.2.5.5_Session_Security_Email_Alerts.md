## เป้าหมาย

ส่งอีเมลแจ้งเจ้าของบัญชีในเหตุการณ์สำคัญ 2 กรณี โดยไม่ทำให้การ Login หรือการออกจากระบบอุปกรณ์อื่นล้มเหลวเมื่อผู้ให้บริการอีเมลขัดข้อง

1. ตรวจพบการเข้าสู่ระบบจากอุปกรณ์ใหม่
2. ผู้ใช้สั่งออกจากระบบอุปกรณ์อื่นทั้งหมดสำเร็จ

## ขอบเขตที่พัฒนา

- ใช้ Resend เดิมผ่าน Server เท่านั้น
- อีเมลอุปกรณ์ใหม่แสดงชื่ออุปกรณ์ เบราว์เซอร์ ระบบปฏิบัติการ เวลา และลิงก์ไปหน้าจัดการ Session
- อีเมลเพิกถอน Session แจ้งจำนวนอุปกรณ์ที่ออกจากระบบและแนะนำให้เปลี่ยนรหัสผ่านทันทีหากผู้ใช้ไม่ได้เป็นผู้ดำเนินการ
- ใช้ Security Event เป็น Idempotency Key เพื่อไม่ส่งเหตุการณ์เดิมซ้ำ
- เก็บเฉพาะผลการส่งและรหัสข้อผิดพลาดที่ปลอดภัยใน `private` schema
- RPC ตรวจ `auth.uid()` และ Session ปัจจุบัน ไม่รับ User ID จาก Browser
- ไม่เก็บ API Key, Token, IP Address หรือเนื้อหาอีเมลใน Audit Ledger
- ความล้มเหลวของอีเมลไม่บล็อก Login และไม่ย้อนผลการเพิกถอน Session

## Environment Variables ฝั่ง Server

- `RESEND_API_KEY`
- `RESEND_FROM_EMAIL`
- `NEXT_PUBLIC_APP_URL`

ห้ามใส่ค่า Secret ลง Source Code, Client Component, Git หรือข้อความ Log

## Acceptance Criteria

- Login อุปกรณ์ใหม่สำเร็จตามปกติและได้รับอีเมลไม่เกินหนึ่งฉบับต่อ Security Event
- Heartbeat รอบถัดไปไม่ส่งอีเมลเหตุการณ์เดิมซ้ำ
- เมื่อออกจากระบบอุปกรณ์อื่นสำเร็จและมีอย่างน้อยหนึ่งอุปกรณ์ที่ถูกเพิกถอน จะได้รับอีเมลสรุปหนึ่งฉบับ
- หากไม่มีอุปกรณ์อื่น ระบบไม่ส่งอีเมล
- หาก Resend ใช้งานไม่ได้ การ Login และคำสั่งเพิกถอน Session ยังคงสำเร็จ
- ตาราง Delivery อยู่ใน `private` schema เปิด RLS และไม่ให้ `anon` หรือ `authenticated` อ่านโดยตรง

## วิธีทดสอบ Local

### กรณีที่ 1 — อุปกรณ์ใหม่

1. เปิด AVENZO ONE ใน Incognito หรือ Browser/อุปกรณ์อีกเครื่อง
2. Login และทำ MFA ตามปกติ
3. เปิดหน้าจัดการอุปกรณ์ที่ `/account/security/sessions`
4. ตรวจว่าอุปกรณ์ใหม่แสดงในรายการ
5. ตรวจ Inbox/Spam ของบัญชีที่ Login ต้องพบอีเมลแจ้งอุปกรณ์ใหม่
6. Refresh หรือใช้งานต่ออย่างน้อยหนึ่งรอบ อีเมลเหตุการณ์เดิมต้องไม่ส่งซ้ำ

### กรณีที่ 2 — ออกจากระบบอุปกรณ์อื่นทั้งหมด

1. ให้บัญชีเดียวกัน Login ค้างไว้อย่างน้อยสองอุปกรณ์
2. ที่อุปกรณ์หลัก เปิด `/account/security/sessions`
3. กดออกจากระบบอุปกรณ์อื่นทั้งหมดและยืนยัน
4. อุปกรณ์หลักต้องยังใช้งานได้ แต่อุปกรณ์อื่นต้องถูกบังคับออกจากระบบ
5. ตรวจ Inbox/Spam ต้องพบอีเมลสรุปการออกจากระบบอุปกรณ์อื่นหนึ่งฉบับ

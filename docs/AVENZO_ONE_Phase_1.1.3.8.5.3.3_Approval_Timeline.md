# Phase 1.1.3.8.5.3.3 — Approval Timeline

สถานะ: Local พร้อมทดสอบ

## เป้าหมาย

ทำให้ Platform Admin มองเห็นลำดับการอนุมัติของหลักฐานแต่ละรายการได้ทันที โดยไม่ต้องไล่ดูหลายการ์ดหรือเดาว่ารายการอยู่ขั้นตอนไหน

## สิ่งที่พัฒนา

- แสดง Timeline เรียงตามเวลา 4 ขั้น: ส่งหลักฐาน, ตรวจหลักฐานผ่าน, ขั้นอนุมัติปัจจุบัน และผลที่จะเกิดหลังยืนยันรับชำระ
- แสดงชื่อผู้ส่งหลักฐานจากสมาชิก Organization เมื่อมีชื่อในระบบ
- แสดงผู้ตรวจหลักฐาน วันเวลา และเหตุผลที่บันทึกไว้
- แสดงสถานะต่างกันระหว่างผู้ตรวจคนแรกและ Platform Admin คนที่ 2
- ใช้ข้อมูลเดิมจาก `billing_transfer_proofs`, `organization_members` และคิวอนุมัติ ไม่เพิ่มตารางใหม่
- การยืนยันจริงยังถูกบังคับโดย RPC ฝั่ง Server และ MFA ตามเดิม

## ขอบเขตความปลอดภัย

Timeline เป็นข้อมูลประกอบการตัดสินใจเท่านั้น ไม่สามารถเปลี่ยน Payment, Invoice หรือ Subscription ได้เอง การเปลี่ยนสถานะจริงยังเกิดแบบ Transaction เดียวเมื่อผู้มีสิทธิ์กดยืนยันรับชำระ

## วิธีทดสอบ Local

1. เข้า `/platform-admin/billing/transfer-proofs` ด้วย Platform Admin ที่ผ่าน MFA
2. ดูส่วน `หลักฐานที่รับรองแล้ว` และเปิดรายการที่รอยืนยันรับชำระ
3. ตรวจว่า Timeline แสดง `ส่งหลักฐาน` และ `ตรวจหลักฐานผ่าน` เป็นสีเขียว พร้อมชื่อและเวลา
4. ถ้าเป็นรายการผู้ดูแล 2 คน ให้บัญชี Admin คนที่ 1 เห็น `รอ Platform Admin คนที่ 2`
5. ออกจากระบบแล้วเข้า Admin คนที่ 2 ให้เห็น `พร้อมให้คุณอนุมัติคนที่ 2`
6. ตรวจว่าขั้นสุดท้าย `สร้าง Payment · ชำระ Invoice · ต่อ Subscription` ยังเป็นสถานะรอดำเนินการก่อนกดยืนยัน

## แผนถัดไป

Phase 1.1.3.8.5.3.4 — Completed Approval History: เพิ่มหน้าค้นย้อนหลังสำหรับรายการที่รับชำระสำเร็จแล้ว พร้อม Timeline ที่จบครบทุกขั้น

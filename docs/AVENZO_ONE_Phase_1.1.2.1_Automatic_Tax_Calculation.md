# AVENZO ONE — Phase 1.1.2.1 Automatic Tax Calculation

## เป้าหมาย

ลดความผิดพลาดจากการกรอกเลขเปอร์เซ็นต์เป็นจำนวนเงิน โดยให้ผู้ใช้งานเลือกวิธีคิดภาษีและเห็นสูตรก่อนสร้าง Invoice

## รูปแบบภาษี

- `ไม่มีภาษี` — ภาษีเป็นศูนย์
- `คำนวณเป็นเปอร์เซ็นต์` — คำนวณจากฐานภาษีหลังหักส่วนลด
- `ระบุจำนวนเงินเอง` — ใช้จำนวนภาษีที่กรอกโดยตรง

## สูตร

1. ฐานภาษี = ราคาตามรอบ − ส่วนลด
2. ภาษี = ฐานภาษี × อัตราภาษี ÷ 100
3. ยอดสุทธิ = ฐานภาษี + ภาษี
4. จำนวนเงินปัดเป็นทศนิยมสองตำแหน่ง

ตัวอย่าง ราคา 1,500 บาท ส่วนลด 0 บาท และภาษี 7%:

- ฐานภาษี 1,500 บาท
- ภาษี 105 บาท
- ยอดสุทธิ 1,605 บาท

## การตรวจสอบ

- ส่วนลดต้องไม่ติดลบและไม่เกินราคาก่อนส่วนลด
- อัตราภาษีต้องอยู่ระหว่าง 0–100%
- จำนวนภาษีและยอดสุทธิต้องไม่ติดลบ
- หน้าตรวจสอบแสดงอัตราภาษี ฐานภาษี จำนวนภาษี และยอดสุทธิก่อนบันทึก
- Invoice ยังคงบันทึกจำนวนภาษีจริงเป็น Snapshot ส่วนวิธีคำนวณ อัตรา และฐานภาษีบันทึกใน Metadata

## ยังไม่รวม

- การตัดสินว่าองค์กรหรือรายการใดต้องเสีย VAT ตามกฎหมาย
- ภาษีมูลค่าเพิ่มแบบราคารวมภาษี (VAT-inclusive)
- ภาษีหัก ณ ที่จ่าย
- การยื่นภาษีหรือเอกสารภาษี Production

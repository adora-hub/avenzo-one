# AVENZO ONE — Phase 1.1.3.8.1 Bank Transfer Channel Setup

สถานะ: Local ผ่าน / อนุมัติ Deploy
วันที่: 10 สิงหาคม 2569

## เป้าหมาย

ให้ Platform Admin ตั้งค่าบัญชีธนาคารหรือพร้อมเพย์ของ AVENZO ONE ที่จะใช้รับชำระแบบ Manual ได้จากหน้า Billing โดยไม่ต้องแก้ฐานข้อมูลเอง

## สิ่งที่ส่งมอบ

- เพิ่มรายการช่องทางรับโอน พร้อมชื่อที่แสดง ธนาคาร/ผู้ให้บริการ ชื่อบัญชี เลขบัญชีหรือพร้อมเพย์ คำแนะนำลูกค้า สถานะ และลำดับการแสดง
- รองรับเพิ่มและแก้ไขช่องทางเดิม แต่ไม่ลบประวัติ
- ใช้ขั้น `ตรวจสอบก่อนบันทึก` ก่อนยืนยันคำสั่งจริง
- ทุกคำสั่งต้องระบุเหตุผลและบันทึก Audit Log
- ตารางเปิด RLS และอนุญาตอ่านเฉพาะ Platform Admin ที่ผ่าน MFA ระดับ AAL2
- การเขียนทำผ่าน RPC ที่ตรวจสิทธิ์ฝั่งฐานข้อมูล พร้อม Command ID ป้องกันคำสั่งล่าสุดซ้ำ
- ไม่มีโค้ดเปลี่ยนสถานะ Invoice, Payment หรือ Subscription

## ขอบเขตความปลอดภัย

Phase นี้เป็นการตั้งค่าปลายทางรับโอนเท่านั้น การเปิดสถานะช่องทางไม่ได้แปลว่าลูกค้าชำระแล้ว และไม่มีการรับรองสลิปอัตโนมัติ

เลขบัญชีและหมายเลขพร้อมเพย์ยังไม่ส่งออกสู่หน้าลูกค้าใน Phase นี้ หน้า Platform Admin แสดงแบบปิดบังเลขส่วนใหญ่ในรายการ

## วิธีทดสอบ Local

1. เข้า `http://localhost:3000/platform-admin/billing` ด้วย Platform Admin ที่ผ่าน MFA
2. เลื่อนไปหัวข้อ `ตั้งค่าช่องทางรับโอน`
3. เลือก `บัญชีธนาคาร` หรือ `พร้อมเพย์`
4. กรอกชื่อที่แสดง ผู้ให้บริการ ชื่อบัญชี เลขบัญชี/พร้อมเพย์ และเหตุผลอย่างน้อย 3 ตัวอักษร
5. รอบแรกแนะนำเลือก `ปิดไว้ก่อน`
6. กด `ตรวจสอบก่อนบันทึก` และตรวจข้อมูลที่ปิดบังเลขส่วนใหญ่
7. กด `ยืนยันบันทึกช่องทาง`
8. ตรวจว่าขึ้นข้อความสำเร็จและการ์ดใหม่ปรากฏทางขวา
9. กด `แก้ไขช่องทางนี้` เปลี่ยนสถานะเป็น `เปิดให้ใช้งาน` ระบุเหตุผลใหม่ และยืนยันอีกครั้ง
10. ตรวจว่า Invoice เดิมยังคงสถานะเดิม ไม่มี Payment ใหม่ และไม่มี Subscription เปลี่ยนแปลง

## Acceptance Criteria

- Platform Admin AAL2 เพิ่มและแก้ไขช่องทางได้
- ผู้ใช้ทั่วไปไม่สามารถอ่านหรือเขียนตารางนี้
- เลขบัญชีถูกจัดเก็บเป็นตัวเลขล้วนและรายการซ้ำถูกปฏิเสธ
- มี Audit ก่อน/หลังการแก้ไข
- การตั้งค่าช่องทางไม่เปลี่ยนสถานะการชำระเงินใด ๆ

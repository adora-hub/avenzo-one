# AVENZO ONE — Phase 1.1.3.8.5.3.1

## Approval Workflow Status UI

สถานะ: Implemented / รอผู้ใช้ทดสอบ Local

### เป้าหมาย

ทำให้ Platform Admin เข้าใจสถานะของหลักฐานและเส้นทางอนุมัติได้ทันที โดยไม่ต้องตีความรหัสสถานะหรือกติกาฝั่งฐานข้อมูล

### สิ่งที่เพิ่ม

- แสดงสถานะ “พร้อมยืนยันรับชำระ”, “รอผู้อนุมัติคนที่ 2” หรือ “พร้อมให้คุณอนุมัติคนที่ 2”
- แสดงเหตุผลที่ระบบเลือกผู้ดูแล 1 คนหรือ 2 คน
- แสดงยอด Invoice เทียบกับวงเงินอนุมัติคนเดียว
- แสดงสัญญาณเสี่ยงเมื่อผู้ตรวจระบุไว้
- แสดงผู้ตรวจหลักฐานคนแรกและเวลาที่ตรวจ
- แปลงสถานะ Invoice และ Subscription เป็นภาษาไทยที่อ่านเข้าใจง่าย

### ขอบเขตความปลอดภัย

- UI มีหน้าที่อธิบายผลการตัดสินใจเท่านั้น
- จำนวนผู้อนุมัติยังคำนวณและบังคับใช้ซ้ำฝั่ง Server
- ไม่มีการเปลี่ยนสูตรยอดเงิน, Payment, Invoice หรือ Subscription
- ไม่มี Secret Key ถูกส่งมายัง Browser

### วิธีทดสอบ Local

1. เปิด `/platform-admin/billing/transfer-proofs` ด้วย Platform Admin ที่ผ่าน MFA
2. รายการยอดไม่เกินวงเงินและไม่เสี่ยง ต้องขึ้น “พร้อมยืนยันรับชำระ” และ “ผู้ดูแล 1 คน”
3. รายการยอดเกินวงเงินหรือถูกระบุว่าเสี่ยง เมื่อเปิดด้วยผู้ตรวจคนแรก ต้องขึ้น “รอผู้อนุมัติคนที่ 2” พร้อมเหตุผล
4. เปิดรายการเดียวกันด้วย Platform Admin อีกบัญชี ต้องขึ้น “พร้อมให้คุณอนุมัติคนที่ 2”
5. ตรวจว่าการ์ดแสดงสถานะ Invoice, สถานะ Subscription, Policy Version และผู้ตรวจคนแรกครบ

### แผนถัดไป

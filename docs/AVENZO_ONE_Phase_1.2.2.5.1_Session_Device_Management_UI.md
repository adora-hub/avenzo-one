# Phase 1.2.2.5.1 — Session & Device Management UI (Read-only)

## เป้าหมาย

เพิ่มหน้าความปลอดภัยให้ผู้ใช้ตรวจสอบ Session และอุปกรณ์ที่เข้าใช้งาน Account ของตนเองได้ โดยยังไม่มีคำสั่งยกเลิก Session ในขั้นนี้

## UI

- เข้าจากปุ่ม `อุปกรณ์ที่เข้าใช้งาน` บน Dashboard หรือ Platform Admin
- แสดงป้าย `อุปกรณ์นี้` สำหรับ Session ปัจจุบัน
- แสดงชื่อเบราว์เซอร์ ระบบปฏิบัติการ เวลา Login เวลาที่ใช้งานล่าสุด Idle Expiry และ Absolute Expiry
- แสดงสถานะภาษาไทย: ใช้งานอยู่, หมดเวลาเพราะไม่ได้ใช้งาน, ครบอายุสูงสุด หรือถูกยกเลิก
- แสดงคำอธิบายชัดเจนว่าขั้นนี้อ่านข้อมูลอย่างเดียว

## ขอบเขตความปลอดภัย

- อ่านรายการผ่าน RPC ที่บังคับ `auth.uid()` และคืนเฉพาะ Session ของผู้เรียก
- ไม่คืน Supabase Session ID ดิบ, Access Token, Refresh Token หรือ IP Address
- ตารางจริงยังอยู่ใน `private` schema และไม่ให้ `anon` หรือ `authenticated` อ่านโดยตรง
- เก็บเฉพาะชื่อแสดงผลของอุปกรณ์ เบราว์เซอร์ และระบบปฏิบัติการ โดยจำกัดความยาวฝั่ง Database
- ใช้ UUID ภายในของ App Session เป็นตัวระบุสำหรับ Phase ยกเลิกอุปกรณ์ในอนาคต

## การทดสอบ

1. Login แล้วเปิด Dashboard
2. กด `อุปกรณ์ที่เข้าใช้งาน`
3. ตรวจว่า Session ปัจจุบันมีป้าย `อุปกรณ์นี้`
4. ตรวจชื่อเบราว์เซอร์ ระบบปฏิบัติการ และเวลาต่าง ๆ
5. ตรวจว่าไม่มีปุ่มยกเลิก Session ใน Phase นี้
6. Login จากอีกเบราว์เซอร์หรืออุปกรณ์ แล้วเปิดหน้านี้ใหม่เพื่อดูรายการเพิ่ม

# AVENZO ONE — Phase 1.1.3.8.3 Transfer Proof Review

## ผลลัพธ์

Platform Admin ที่ยืนยัน MFA แล้วมีหน้าคิวสำหรับเปิดหลักฐานจาก Private Storage ตรวจยอด วันเวลา ช่องทางรับโอน และเลือก `รับรอง` หรือ `ปฏิเสธ` พร้อมเหตุผลสำหรับ Audit Log

การรับรองในเฟสนี้หมายถึง **หลักฐานผ่านการตรวจเท่านั้น** ไม่ได้หมายความว่า Invoice ชำระสำเร็จ

## ความปลอดภัย

- หน้าและ RPC ต้องเป็น Platform Admin สถานะ Active และ JWT ระดับ `aal2`
- ไฟล์เปิดผ่าน Signed URL อายุ 120 วินาที ไม่เปิด Bucket เป็น Public
- ใช้ `review_command_id` ป้องกันคำสั่งซ้ำ
- Lock หลักฐานและ Invoice ก่อนตัดสิน เพื่อกัน Admin สองคนกดชนกัน
- Unique Partial Index อนุญาตหลักฐานสถานะ `accepted` ได้เพียงหนึ่งรายการต่อ Invoice
- รับรองได้เฉพาะ Invoice ที่ยังเป็น `pending`
- เหตุผลยาว 3–500 ตัวอักษรและถูกบันทึกผ่าน Billing Audit Trigger
- Migration นี้ไม่สร้าง Payment และไม่แก้สถานะ Invoice หรือ Subscription

## วิธีทดสอบ Local

1. Login ด้วย Platform Admin และผ่านรหัส MFA 6 หลัก
2. เปิด `http://localhost:3000/platform-admin/billing`
3. กด `ตรวจหลักฐานโอน`
4. ต้องเห็น Invoice ที่ลูกค้าเพิ่งส่งหลักฐาน พร้อมยอดตาม Invoice และยอดที่ลูกค้าแจ้ง
5. กด `เปิดไฟล์หลักฐาน` ต้องเปิดไฟล์ Private ในแท็บใหม่
6. ตรวจชื่อบัญชี ช่องทางรับโอน ยอด วันเวลา และไฟล์
7. กด `ตรวจแล้ว · รับรองหลักฐาน` หรือ `ปฏิเสธหลักฐาน`
8. ตรวจการ์ด `ตรวจสอบครั้งสุดท้าย` กรอกเหตุผล แล้วกดยืนยัน
9. รายการต้องหายจากคิวและขึ้นข้อความผลสำเร็จ
10. กลับหน้า Billing และตรวจว่า Invoice ยังเป็น `รอชำระ`

กรณีป้องกัน: กดยืนยันรายการเดิมซ้ำ, รับรองหลักฐานที่ Invoice ไม่ได้รอชำระ, ใช้บัญชีที่ไม่ใช่ Platform Admin หรือยังไม่ผ่าน MFA

## แผนถัดไป

Phase 1.1.3.8.4 — Fulfillment สำหรับหลักฐานที่รับรองแล้ว: สร้าง Payment แบบ Idempotent, เปลี่ยน Invoice เป็นชำระแล้ว และดำเนิน Subscription ภายใน Transaction เดียว พร้อมมาตรการอนุมัติที่เหมาะสมก่อนแตะเงินจริง

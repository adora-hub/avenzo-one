# Phase 1.2.2.5.2 — ออกจากระบบเป็นรายอุปกรณ์

## ผลลัพธ์

- ผู้ใช้ยกเลิก Session ที่เป็นของบัญชีตนเองได้ทีละอุปกรณ์
- ไม่มีปุ่มยกเลิกบนอุปกรณ์ปัจจุบัน และ RPC ปฏิเสธซ้ำอีกชั้นฝั่งฐานข้อมูล
- ก่อนดำเนินการมีหน้าตรวจสอบและปุ่มยืนยันชัดเจน
- บันทึกเหตุการณ์ `session_device_revoked` ใน Private Audit Log
- ไม่เปิดเผย Supabase Session ID, Access Token, Refresh Token หรือ IP Address

## ขอบเขตความปลอดภัย

Supabase Auth ไม่มี Client API สำหรับตัด Session อื่นที่เลือกเพียงรายการเดียว ระบบจึงยกเลิก App Session ของ AVENZO ONE และ Middleware จะบังคับออกจากระบบเมื่ออุปกรณ์นั้นเปิดหน้าที่มีการป้องกันครั้งถัดไป ส่วน JWT เดิมจะหมดอายุตามอายุ Token ของ Supabase

## วิธีทดสอบ Local

1. Login บัญชีเดียวกันบน Chrome ปกติ และหน้าต่างไม่ระบุตัวตนหรือเบราว์เซอร์อีกตัว
2. ที่อุปกรณ์หลัก เปิด `/account/security/sessions`
3. ตรวจว่าการ์ด `อุปกรณ์นี้` ไม่มีปุ่มออกจากระบบ
4. กด `ออกจากระบบอุปกรณ์นี้` บนอีกอุปกรณ์ แล้วกดยืนยัน
5. กลับไปอีกอุปกรณ์และเปิดหน้าถัดไป ระบบต้องพากลับหน้า Login พร้อมแจ้งว่า Session ถูกยกเลิก
6. อุปกรณ์หลักต้องยังใช้งานต่อได้ และการ์ดอุปกรณ์ที่ถูกตัดต้องเปลี่ยนเป็น `ออกจากระบบแล้ว`

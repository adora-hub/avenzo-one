# AVENZO ONE — Phase 1.1.3.8.2 Private Slip Upload

## ผลลัพธ์

ลูกค้าที่มีสิทธิ์ดูข้อมูล Billing ของ Organization สามารถเลือก Invoice ที่รอชำระ เลือกช่องทางรับโอน กรอกยอดและเวลา แล้วแนบหลักฐานเพื่อรอเจ้าหน้าที่ตรวจสอบได้

การแนบหลักฐาน **ไม่ใช่การยืนยันว่าชำระสำเร็จ** และขั้นตอนนี้ไม่เปลี่ยนสถานะ Invoice, Payment หรือ Subscription

## ความปลอดภัย

- Bucket `billing-transfer-proofs` เป็น Private
- จำกัดไฟล์ไม่เกิน 5 MB
- รับเฉพาะ JPG, PNG, WebP และ PDF
- Server เป็นผู้สร้าง path ในรูป `organization/invoice/user/proof.ext`
- ผู้ใช้ Upload ได้เฉพาะ path ที่ Server เตรียมให้บัญชีของตน
- ก่อนเปลี่ยนเป็น `submitted` ระบบตรวจว่า object มีอยู่จริง และ MIME/ขนาดตรงกับข้อมูลที่เตรียมไว้
- การอ่านไฟล์ต้องเป็นผู้มีสิทธิ์ของ Organization, ผู้ Upload หรือ Platform Admin ที่ผ่านเงื่อนไขความปลอดภัย
- ทุกการสร้างและเปลี่ยนสถานะหลักฐานมี Billing Audit Log
- Supabase Security Advisor และ Performance Advisor หลังลง Migration ไม่พบคำเตือน

## ลำดับการทำงาน

1. เลือก Invoice ที่มีสถานะรอชำระ
2. เลือกบัญชีธนาคารหรือพร้อมเพย์ที่เปิดใช้งาน
3. กรอกยอด เวลา และเลือกไฟล์หลักฐาน
4. กดตรวจสอบก่อนส่งหลักฐาน
5. ยืนยันส่ง ระบบจึงเตรียม path, Upload เข้า Private Storage และบันทึกสถานะ `submitted`
6. Invoice ยังคงรอชำระจนกว่าจะมีขั้นตอนตรวจและอนุมัติใน Phase ถัดไป

## มาตรฐาน UI ที่ใช้

- Dropdown แยกพื้นที่ลูกศรด้านขวาและเว้นระยะจากข้อความ เพื่อให้มองเห็นจุดกดชัดเจน
- ช่องแนบไฟล์รองรับทั้งการลากไฟล์มาวางและการคลิกเลือกจากเครื่อง
- ตรวจชนิดและขนาดไฟล์ทันที ก่อนเข้าสู่หน้าตรวจสอบครั้งสุดท้าย
- เมื่อเลือกแล้วแสดงชื่อ ขนาด และภาพตัวอย่างสำหรับไฟล์รูป พร้อมปุ่มลบไฟล์
- บนหน้าจอขนาดเล็ก การ์ดไฟล์และปุ่มจัดเรียงใหม่โดยไม่ล้นกรอบ
- ใช้ Hover เปลี่ยนสีเบา ๆ โดยไม่มีเงา ตาม Design System กลางของ AVENZO ONE

## วิธีทดสอบ Local

1. Login ด้วยบัญชี Owner หรือ Admin ของ Organization
2. เปิดหน้า `จัดการ Workspace`
3. ไปที่การ์ด `แจ้งโอนและแนบหลักฐาน`
4. เลือก Invoice และช่องทางรับโอน แล้วลากไฟล์มาวางหรือคลิกเลือกไฟล์ที่รองรับไม่เกิน 5 MB
5. กด `ตรวจสอบก่อนส่งหลักฐาน` แล้วตรวจข้อมูลบนการ์ดสรุป
6. กด `ยืนยันส่งหลักฐาน`
7. ต้องเห็นข้อความว่าส่งหลักฐานแล้วและสถานะ `ส่งหลักฐานแล้ว · รอตรวจ`
8. ตรวจว่า Invoice ยังเป็น `รอชำระ`

กรณีที่ต้องปฏิเสธ: ไฟล์ `.txt`, ไฟล์เกิน 5 MB, Invoice ที่ชำระแล้ว และช่องทางรับโอนที่ปิดใช้งาน

## แผนถัดไป

Phase 1.1.3.8.3 — คิวตรวจหลักฐานสำหรับ Platform Admin: เปิดดูไฟล์ Private แบบมีอายุ, ตรวจยอด/เวลา/บัญชี, อนุมัติหรือปฏิเสธพร้อมเหตุผล และยังต้องป้องกันการยืนยันซ้ำก่อนสร้าง Payment จริง
